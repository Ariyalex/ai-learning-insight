## 📌 Tentang Project

AI Learning Insight adalah aplikasi dashboard pembelajaran yang otomatis ngasih insight ke user berdasarkan aktivitas belajar mereka.  
Sistem ini ngambil data, ngejalanin machine learning, dan nampilin insight yang mudah dibaca user - semuanya otomatis.

Project ini terdiri dari:

- 🎨 **Frontend** (React + Vite + ShadCN UI)
- 🧠 **Backend** (Express + PostgreSQL)
- 🤖 **ML Internal Service** (Detect Model + Gemini AI)

---

## 🚀 Fitur Utama

### 🔐 **Authentication**
- Login dengan email & password
- Token-based auth (Access + Refresh Token)

### 📊 **Dashboard Insight**
- Prediksi pola belajar user (cluster)
- Insight aktivitas, akademik, dan learning type
- Tampilan data yang clean & mudah dipahami
- Grafik aktivitas bulanan

### 🔁 **Insight Refresh**
- User bisa refresh insight kapanpun  
- Insight ditulis ke log untuk kebutuhan history

### 📜 **History Insight**
- Semua insight tersimpan di log
- User bisa klik insight lama → auto load ke dashboard
